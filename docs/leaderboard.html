Tabular Foundation Model(TFM) 과 GBDT 를 같은 5-fold CV·같은 피처, 튜닝 없는 기본 설정으로 비교.

표 읽는 법
  • 평균 CV 순위 = 대회마다 (순위−1)/(모델 수−1) 의 평균. 0 = 항상 1위, 1 = 항상 꼴찌. 모델마다 실행한 대회가 달라 대략적인 비교.
  • 종합·히트맵은 모델마다 대회별로 CV 가 가장 좋은 설정 하나만 셈 (컨텍스트 변형 ctx 전체·ctx 20만·kNN 1000 포함).
  • 시간 = 5-fold 합계 (학습 + 검증·테스트 예측). s/1K = 시간 ÷ 예측 행 수 × 1000 (예측 행 = 학습 행 + 테스트 행 × 5). 작은 대회는 고정 비용 때문에 s/1K 가 부풀려짐.
  • 환경이 다르면 시간 비교 불가: DBX H100 (TFM) · DBX CPU4 (GBDT, serverless 4코어) · DBX A10G · Kaggle T4. s/1K (DBX) = H100·CPU4 실행만의 중앙값.
  • LB = Kaggle public 점수 기준 위치. 종료 대회는 늦은 제출이라 실제 순위표에는 없음. — = 미제출.
  • TFM 컨텍스트 상한 은 무작위 샘플. 상한을 푼 실행은 일부 모델(kumo)만 있어 그 대회들의 순위 일부는 모델 차이가 아니라 컨텍스트 차이.
  • Otto·GiveMeSomeCredit·Amazon 등 공개 데이터는 TFM 사전학습에 들어갔을 수 있어 CV 가 부풀었을 수 있음 (LB 는 영향 없음).
